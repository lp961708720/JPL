# 治愈系手绘动画短片一键流水线技能

本技能将工作台固化为「**先定剧情与穿搭 → 查库复用/缺啥补啥（自动沉淀）→ 出工单生分镜图 → 图生视频 → 剪映合成发布**」5 步牵手式流水线。严格按以下全局原则与五大流程执行。

## 全局规则：5 步牵手引导原则
1. **一次只推进一步**：不要在用户还在选剧情或补资产时，把剪映、图生视频的参数全堆在回复里。
2. **每个流程回复末尾必须附带标准「当前进度指引框」**：
   ```markdown
   ---
   - **📍 当前进度**：第 X 步 / 共 5 步（阶段名）
   - **👉 你现在只需做**：具体到文件、操作、文件名与存放路径
   - **💬 做完回来直接回复**：`xxx`（明确口令）
   ```

## 流程 0：按需生成资产图（主角定妆图 / 剧情新增场景与宠物补画）

**触发词**：「帮我设计角色」「帮我生成资产」「补资产」「我没有参考图」「做定妆图」

1. **读取参考规范与现有资产**：
   - 并行读取 `.agents/skills/ghibli-episode-pipeline/references/prompt_guide.md`（查看「零、资产定妆图与空景图生图公式」）与 `01_资产库/资产档案.md`，并检查 `01_资产库/01_角色参考图/` 是否已有主角图。
2. **判断需求类型**：
   - **情况 A：库里还没有主角定妆图** → 极简 2–3 问确认主角长相发型与画幅（若用户已说清则跳过），按 `prompt_guide.md`「主角定妆图模板」输出 Prompt，存为 `01_资产库/01_角色参考图/主角.png`（或类似直观中文名）。
   - **情况 B：已有主角图，要按剧情单补 1 张新场景空景图或新宠物图** → 直接锁定当前 `01_角色参考图/` 中的主角参考图作为画风参考，按 `prompt_guide.md` 对应模板输出 Prompt，要求严格空景无人物（场景图）或单独宠物全身（宠物图），并明确保存路径（`01_资产库/02_核心场景图/<场景名>.png` 或 `01_资产库/01_角色参考图/<宠物名>.png`）。
3. **末尾进度指引**：
   - 告知用户存好图后回来回复 **「补好了」**（若正在策划某一期）或 **「扫描我的资产库」**。

## 流程 A：资产扫描与建档

**触发词**：「扫描我的资产库」「登记资产」「更新资产」

1. **检查目录文件**：
   - 查看以下三个文件夹中的所有图片文件（`.png`、`.jpg`、`.jpeg`、`.webp`）：
     - `01_资产库/01_角色参考图/`
     - `01_资产库/02_核心场景图/`
     - `01_资产库/03_画风参考图/`
2. **空库判断**：
   - 如果三个文件夹中**没有任何图片文件**，不要强行编造档案。温柔告知用户还没有检测到参考图，引导：
     - 把已有的图放进对应文件夹；
     - 或者直接发 **「帮我生成资产」** 从零生成主角定妆图，也可以直接发 **「定剧情」** 先定第一期故事再按需画图。
3. **看图提炼特征**：
   - 对找到的每一张未登记图片（或需更新的图片），调用 `read_file` 直接查看图像内容。
   - 分别提炼出：
     - **角色（主角/配角）**：准确的相对路径与文件名、角色代号、中文外貌描述（年龄感、脸型神态、发型发色、以及参考图原穿搭备注）、英文锚定词。**关键规则**：若 `资产档案.md` 开启「锁脸锁发型、按题材换装」，主角的英文锚定词**只锁定脸型、五官、发型发色与气质，不把原图服装写死**，方便每期按剧情换装。
     - **宠物**：准确的相对路径与文件名、宠物代号、毛色体型与项圈特征描述、英文锚定词。
     - **核心场景**：准确的相对路径与文件名、场景代号、空间结构、主要家具与厨具位置、窗户朝向与采光、主色调与材质，以及对应的英文锚定词。
     - **画风参考（如有）**：线稿粗细与颜色、上色笔触、光影对比特点，以及对应的英文风格词。
4. **写入档案**：
   - 读取并更新 `01_资产库/资产档案.md`（保留用户已填写的频道基础设定与原则，替换/追加表格行）。
5. **汇报用户并附进度指引框**：
   - 简明汇报新登记或当前已沉淀的角色与场景清单，引导下一步发 **「定剧情」** 或 **「生成试水版」**（若是从补资产环节回来，引导发 **「继续」**）。

## 流程 B：先定剧情与穿搭 → 资产查缺复用 → 整期工单生成

**触发词**：
- **第 1 步策划 / 生成**：
  - **新手试水版（6–8 镜，30–45 秒）**：「定剧情」「策划新一期」「生成试水版」「新手试水」「来一期短的」
  - **标准精简版（18–25 镜，1.5–2 分钟）**：「生成新一期」「再来一期」「排一期新视频」「出工单」
- **补完缺失资产后接着出工单**：「补好了」「继续」
- **画幅判断**：默认 `16:9 横屏`；若 `01_资产库/资产档案.md` 中已设定为 `9:16` 或用户当次指令明确提到“竖屏 / 小红书 / 抖音”，则全套生图提示词自动切换为 `9:16 竖屏` 后缀。

### Step 1：同步资产库 + 确定本期剧情、天气与专属穿搭
1. **静默同步检查**：先扫描 `01_资产库/01_角色参考图/`、`01_资产库/02_核心场景图/`、`01_资产库/03_画风参考图/`。如果文件夹里有尚未写入 `01_资产库/资产档案.md` 的新图，**先自动执行流程 A 看图登记**，确保不漏掉任何刚刚放入的复用/补画资产。
2. **并行读取参考文件**：
   - `01_资产库/资产档案.md`
   - `02_选题排期/已生成历史.md`
   - `.agents/skills/ghibli-episode-pipeline/references/topic_matrix.md`
   - `.agents/skills/ghibli-episode-pipeline/references/prompt_guide.md`
3. **定本期剧情与穿搭**：
   - 如果用户刚说「定剧情」「策划新一期」「生成试水版」且**还没有确定具体故事**：
     - 可先结合 `已生成历史.md` 与 `topic_matrix.md` 给用户提供 **2–3 个不重样、试水高成功率的剧情候选**（含推荐主题、出场场景、预计是否需要新画场景、以及对应穿搭设想），或当用户说“你帮我定 / 直接出”时直接选定最优方案。
   - 若用户已明确故事方向或选择了方案（或从「补好了 / 继续」回来延续上一轮确认的方案），锁定本期全部要素：
     - **期号**（无记录则为 `EP01`，已有 `EP01` 则为 `EP02`，依此类推）与 **规格 / 画幅**
     - **主题标题与剧情大纲**（遵循去重规则：不撞历史具体事件、品类轮换、天气防撞车）
     - **天气与时段**
     - **本期主角专属穿搭（锁脸锁发型、按题材换装）**：给出温暖复古日系居家风的中文描述 + 统一英文穿搭词（全期所有镜头统一复用；做饭题材可配围裙，书桌/客厅/慢生活题材不穿围裙且英文中加 `no apron`，室内配居家袜或拖鞋）
     - **本期所需资产清单**：主角 + 本期用到的宠物（如有）+ 本期用到的核心场景（可复用已有场景，也可因精彩剧情引入新场景）。

### Step 2：资产库查缺（已有直接复用 vs 缺啥只补画啥）
逐一核对本期所需资产是否都已在 `01_资产库/` 中存在并登记在 `资产档案.md`：

- **分支 B1：存在缺失资产（例如库里已有主角，但本期需要新场景或新宠物）**
  - **暂不生成 `03_成片工单/` 下的分镜与历史记录**（避免写入不存在的假路径）。
  - 向用户清晰输出：
    1. **本期剧情与穿搭方案**（主题、天气、主角这期穿什么）；
    2. **资产复用对照表**：逐行标明「`✅ 库里已有，直接复用`（附路径）」与「`🆕 本期新增，需先补画`（标清建议文件名）」；
    3. **缺失资产专属生图指南**：只针对标 `🆕` 的那 1–2 张图，按 `prompt_guide.md` 模板给出可直接复制进 Gemini 的英文 Prompt，**明确写清要上传库里已有的主角参考图作画风参考**，以及存成什么文件名、放进哪个文件夹；
    4. 末尾附 **第 2 步进度指引框**：告诉用户把缺失的图放进文件夹后，回来回复 **「补好了」**（或 **「继续」**），系统会自动看图沉淀入库并立刻生成本期全套施工单！

- **分支 B2：本期所需资产已全部齐备**
  - 直接进入 **Step 3**。

### Step 3：创建工单目录与 3 份施工单 + 4 个素材文件夹
在 `03_成片工单/EPXX_<主题简称>/` 下创建以下文件与目录（用 `write_file` 创建占位说明文件确保空素材目录生成）：
- `素材_图片/把Gemini生成的分镜图存这里_按S01到SXX命名.txt`
- `素材_视频/把图生视频生成的片段存这里_按S01到SXX命名.txt`
- `素材_音频/把环境音和纯音乐存这里.txt`
- `最终成片/剪映导出的完整视频放这里.txt`

并撰写以下 3 份完整施工单：

#### 1. `01_分镜与生图提示词.md`
- **顶部概览**：期号、本期规格（`新手试水版 6–8 镜 / 30–45 秒` 或 `标准精简版 18–25 镜 / 90–120 秒`）、画幅（`16:9 横屏` 或 `9:16 竖屏`）、自动选定的主题与中/英文标题、所属品类、天气时段、总镜头数、预计总时长、出场资产清单与对应参考图路径。若 `资产档案.md` 设定为「按题材换装」，则额外写明「**本期主角专属穿搭**（温暖复古日系居家风，含中文描述与统一英文词；做饭题材可配围裙、书桌/客厅不穿围裙，全期所有镜头统一复用）」。
- **分镜结构**：
  - 若为**试水版**：严格按 `topic_matrix.md` 的**三幕试水模板**编排（环境引入 1–2 镜 → 核心制作/仪式高潮 3–4 镜 → 享用与余韵收尾 2 镜）。
  - 若为**标准版**：严格按 `topic_matrix.md` 的**五幕模板**编排（环境引入 3–4 镜 → 准备阶段 4–5 镜 → 烹饪/核心仪式高潮 6–8 镜 → 享用治愈 3–5 镜 → 余韵收尾 2 镜）。
  - 注意远景/中景/特写交替、冷色调与暖色调过渡。
- **逐镜明细表 / 卡片**（`S01` ~ `SXX`，逐镜完整写出，**严禁偷懒省略或写“同上”**）：
  - 镜号与建议时长（例如 `S01 | 5秒 | 远景`）
  - 中文画面描述（清晰说明人物位置、光影、动作状态）
  - **操作：需在 Gemini 上传的参考图**：
    - 精确列出基础资产相对路径，例如 `01_资产库/01_角色参考图/主角_女孩_定妆图.jpg` + `01_资产库/02_核心场景图/厨房.png`；
    - **【前镜垫后镜】强制规则**：凡是同一锅具、碗碟、桌面或食物的连续推进镜头（例如切好食材 → 下锅煎煮 → 沸腾冒泡 → 盛入同款碗中），**必须明确标注额外上传上一镜刚生成好的图**，例如 `+ 本期素材_图片/S03.png（前镜垫后镜，锁定锅具与食物样式不变）`。
  - **可直接复制进 Gemini 的英文生图 Prompt**：严格遵循 `references/prompt_guide.md` 公式，内嵌 `资产档案.md` 的英文锚定词 + 垫图绑定句（若启用按题材换装，使用 `prompt_guide.md` 的「锁脸锁发型 + 本期专属穿搭」绑定句，避免照搬参考图原服装，非做饭题材需明确写 `no apron`；连续镜头必加 `Continue directly from the previous shot reference image...` 衔接绑定句）+ 对应画幅后缀（16:9 或 9:16）+ `no text, no watermark`。
  - 保存文件名：`素材_图片/S01.png`

#### 2. `02_图生视频提示词.md`
- **顶部说明**简明使用方法：
  - 底图放进去，选择 5 秒时长，选对应工具复制对应语言 Prompt；
  - **可灵 / 即梦「首尾帧」进阶省事提示**：凡是相邻两镜画面衔接非常紧密的连续动作（工单中标出建议组别），可在可灵/即梦里试着把 `SXX.png` 放首帧、`S(XX+1).png` 放尾帧，一次生成丝滑过渡；
  - **Veo 3 原生环境音提示**：提示词自带 `Silent character, no dialogue... only soft ambient sound of ...`，如果 Veo 3 生成的片段自带干净的雨声、煎炸声且没人说话，剪辑时可直接留用原声，无需再去下音效。
- 与 `S01` ~ `SXX` **逐镜一一对应**，每镜包含：
  - 上传底图：`素材_图片/S01.png`（若可配合下一镜做首尾帧，注明“可选首尾帧搭档：`S02.png`”）
  - **Veo 3 / 国际模型英文动态 Prompt**：遵循 `prompt_guide.md` 规范，含克制的动作/光影/镜头微动描述 + 强制防人声后缀（`Silent character, no dialogue, no talking, no voice, only gentle ambient sound of ...`）
  - **可灵 / 即梦 中文动态 Prompt**：聚焦局部环境微动、缓慢推拉、轻微神态变化，避免复杂肢体交互
  - **小白防穿帮提示**：如“本镜含手部持筷，优先让热气和雨滴动，人物只做轻微笑/微点头；若手指变形可直接再抽一次或删减到 3.5 秒”。
  - 保存文件名：`素材_视频/S01.mp4`

#### 3. `03_剪辑与音效发布单.md`
- **一、3 层音频方案（兼顾剪映直搜 + Veo 3 省事技巧）**：
  - 顶部先给出 **Veo 3 原生音留用规则**：若该镜用 Veo 3 生成且环境声自然无杂音、无人声，可直接保留视频原声（调至 `-12dB ~ -18dB`），省去单独找音效；其余静音镜头或可灵/即梦生成的无声片段，按下方 3 层方案补音。
  1. 底层持续环境音（全片贯通，音量 `-18dB ~ -22dB`）：同时给出 **剪映自带音效库中文搜索词**（首选，零门槛）与 **免费音效站英文搜索词**（如 `雨打玻璃` / `soft rain on window ambient`）。
  2. 中层 ASMR 卡点音效表（精确列出哪个镜号配什么声音、音量 `-12dB ~ -16dB`）：每行同时给出 **剪映音效库中文直搜词** 与 **英文备用词**。
  3. 顶层轻音乐 BGM（音量 `-24dB ~ -28dB`）：给出 **剪映音乐库中文直搜词**（如 `治愈系纯钢琴`、`温暖木吉他`）以及 **YouTube Audio Library 免费方向**（如 Aakash Gandhi 风格轻钢琴）。
- **二、剪映（CapCut）极简剪辑 Checklist**：
  - 时间轴导入顺序、90% 硬切 + 幕间 0.5 秒叠化、全片微调暖色色温/轻微暗角与胶片颗粒以统一不同镜头色差、右下角添加半透明频道水印（读取 `资产档案.md` 中的水印文本）。
- **三、封面与双平台发布包装**：
  - **无字封面推荐**：指定 **2 个最适合做无字封面** 的镜号（直接拿 `素材_图片/SXX.png` 略提饱和度即可，**不加文字**）。
  - **YouTube 海外发布包**：
    - **3 组中/英双语标题**（符合 `[天气/季节情绪] + [具体生活/美食动作] + [治愈关键词]`）
    - **YouTube 简介模板** + **按本期镜头累加时长算好的章节时间戳**（试水版 3 个章节，标准版 5 个章节）+ **20 个中英文 SEO 标签**
    - **合规提醒**：发布时在 YouTube Studio 勾选「经过修改或合成的内容（Altered or synthetic content）」。
  - **国内平台（小红书 / 抖音 / B站）速贴发布包**：
    - **3 个中文高点击治愈标题**
    - **1 段简短有氛围感的正文文案** + **10 个中文热门话题标签**（如 `#治愈系动画 #AI动画 #沉浸式做饭 #深夜食堂 #吉卜力风`）
    - **合规提醒**：发布时按平台提示勾选/声明「AI 生成内容」标识。

### Step 4：更新历史记录与单步汇报（只聚焦第 3 步）
1. 将本期记录追加写入 `02_选题排期/已生成历史.md` 表格（含 `规格` 列，如 `试水版 16:9` 或 `标准版 16:9`），状态设为 `待制作`。
2. 在回复中向用户简要展示：
   - 本期规格（试水版或标准版）、画幅、总镜头数、主题与本期专属穿搭

## 流程 C：单镜修复与排期维护

### C-1：单镜穿帮修复（「EPXX 第 X 镜穿帮了/帮我改」「优化镜头」）
1. 定位 `03_成片工单/EPXX_*/01_分镜与生图提示词.md` 与 `02_图生视频提示词.md`。
2. 读取对应镜号的内容及 `资产档案.md`。
3. 诊断常见原因（手部握持特写过多、双人复杂互动、物体在画面中大跨度移动、未做前镜垫后镜导致道具变样、镜头描述过于拥挤等），保留原剧情目的与角色/场景锚定词，**切换成更稳妥的替代构图或微动方案**（例如：特写改成略带前景虚化的中景、夹菜动作改成“端着碗热气腾腾微笑”或“食物表面热汤冒泡特写”）。
4. 使用 `edit_file` 更新对应工单中的该镜头，清楚告诉用户改了哪里、需要重抽图片还是只重抽视频即可，并在末尾附上当前进度指引框。

### C-2：排期维护（「标记 EPXX 已完成」「做完了」「查看排期」）
- 读取 `02_选题排期/已生成历史.md`。
- 若是查看排期，清晰总结已制作、待制作数量及上一期主题与规格。
- 若是标记完成（用户说「做完了」时默认标记最近一期 `待制作` 的剧集），使用 `edit_file` 将对应期号状态从 `待制作` 改为 `已完成 (YYYY-MM-DD)`，告知用户累计已完成期数，并引导随时可发 **「定剧情」** 开始下一期。

## 流程 D：智能进度检查与单步引导（防迷路导航）

**触发词**：「下一步」「接下来做什么」「现在到哪一步了」「我该做什么」

1. **自动巡检工作区状态**：
   - 检查 `01_资产库/` 下图片与 `01_资产库/资产档案.md`；
   - 读取 `02_选题排期/已生成历史.md` 查找是否存在 `待制作` 的最新一期（`EPXX`）；
   - 如果存在待制作工单，列出 `03_成片工单/EPXX_*/` 下 `素材_图片/`、`素材_视频/`、`最终成片/` 中的实际图片/视频文件（排除 `.txt` 占位说明），并读取该期 `01_分镜与生图提示词.md` 确认总镜头数（如 7 镜）。
2. **按真实进度精准给出单步指引**：
   - **情况 1：目前没有任何 `待制作` 工单**
     - 若连主角图都没有 → 引导执行 **流程 0**（发「帮我生成资产」）；
     - 已有主角图（或已有部分场景） → 引导进入 **第 1 步｜定剧情与穿搭**（发「定剧情」或「生成试水版」）。
   - **情况 2：有 `待制作` 工单，但 `素材_图片/` 还没生齐**（文件数 = 0 或 少于总镜数）
     - 精准报出进度（例如：“`EP01` 共 7 镜，目前 `素材_图片/` 里已有 `S01`~`S03`，还差 `S04`~`S07`”）；
     - 引导打开 `01_分镜与生图提示词.md` 继续在 Gemini 补齐剩余图片；完成后再发 **「下一步」**。
   - **情况 3：`素材_图片/` 已齐，但 `素材_视频/` 还没转齐**（文件数 = 0 或 少于总镜数）
     - 引导进入 **第 4 步｜图生视频**：告诉用户打开 `02_图生视频提示词.md`，把 `素材_图片/` 里的图逐个放进 Veo 3 / 可灵 / 即梦 转成 5 秒视频，存为 `素材_视频/S01.mp4`~`SXX.mp4`（提醒若某镜手指/动作穿帮，随时发「EPXX 第 X 镜穿帮了」）；全部转完后再发 **「下一步」**。
   - **情况 4：`素材_视频/` 已齐，但 `最终成片/` 还是空的**
     - 引导进入 **第 5 步｜剪映合成与发布**：告诉用户打开 `03_剪辑与音效发布单.md`，照着时间轴顺序、剪映音效中文词、无字封面推荐与平台发布文案合成导出到 `最终成片/`；发布完回来发 **「做完了」** 归档！
   - **情况 5：`最终成片/` 已有视频文件**
     - 恭喜出片！提醒回复 **「做完了」** 把这一期归档为已完成，并可随时发 **「定剧情」** 开启下一期。
