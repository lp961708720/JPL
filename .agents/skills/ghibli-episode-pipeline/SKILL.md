# 治愈系手绘动画短片一键流水线技能

本技能用于将用户的固定视觉资产转化为可重复执行的「零基础资产定制 → 自动选题 → 分镜生图 → 图生视频 → ASMR 剪辑发布」全套施工工单。严格按以下四大流程执行。

---

## 流程 0：零基础生成首套资产图

**触发词**：「帮我设计角色」「帮我生成资产」「我没有参考图」「做定妆图」

1. **读取参考规范**：
   - 并行读取 `.agents/skills/ghibli-episode-pipeline/references/prompt_guide.md`（查看「零、首套固定资产定妆图生图公式」）与 `01_资产库/资产档案.md`。
2. **极简 3 问确认设定**（如果用户已经在消息里说清了设定，直接跳过提问，按用户设定出 Prompt）：
   - ① **主角长相与穿搭**：想要男生还是女生？大概年龄感、发型发色、日常穿什么颜色的衣服/围裙？
   - ② **要不要小宠物**（可选）：比如小橘猫、白猫、小柴犬，还是只要主角一人？
   - ③ **固定主场景与画幅**：最常拍的房间是**带大窗户的温馨小厨房**，还是**窗边书桌/客厅**？平时主要发横屏（16:9，YouTube/B站）还是竖屏（9:16，小红书/抖音）？
3. **输出可直接复制进 Gemini 的首套资产英文生图 Prompt**：
   - **主角定妆图 Prompt**：遵循 `prompt_guide.md`「主角定妆图模板」，单人正面半身或全身、柔和室内自然光、简洁浅色或素雅背景（无杂乱道具），方便后续提取特征。明确指示：在 Gemini 生成后挑最满意的一张，存为 `01_资产库/01_角色参考图/主角.png`。
   - **宠物定妆图 Prompt（如有）**：遵循 `prompt_guide.md`「宠物定妆图模板」，清晰展现毛色、体型与项圈等标志特征，存为 `01_资产库/01_角色参考图/<宠物名>.png`。
   - **核心场景空景图 Prompt**：遵循 `prompt_guide.md`「核心场景空景图模板」，严格空景无人物（`empty cozy room, no people, no characters`），明确窗户朝向、灶台/书桌位置与暖灯，按用户选择带 `16:9` 或 `9:16` 后缀。**同时提醒用户**：生成场景图时，可以把刚刚存好的 `主角.png` 一起上传到 Gemini，并在提示词开头加上“仅参考画风、线条与色彩质感，画面中不要出现任何人物”，这样主角和房间的画风会完全统一！存为 `01_资产库/02_核心场景图/<场景名>.png`。
4. **明确下一步**：
   - 告诉用户：“把生好的图片放进上面对应的文件夹后，回到这里发一句 **「扫描我的资产库」**，我就会自动看图建档；接着说 **「生成试水版」** 就能低成本做出第一条短片！”

## 流程 A：资产扫描与建档

**触发词**：「扫描我的资产库」「登记资产」「更新资产」

1. **检查目录文件**：
   - 使用命令行或列目录查看以下三个文件夹中的所有图片文件（`.png`、`.jpg`、`.jpeg`、`.webp`）：
     - `01_资产库/01_角色参考图/`
     - `01_资产库/02_核心场景图/`
     - `01_资产库/03_画风参考图/`
2. **空库判断**：
   - 如果三个文件夹中**没有任何图片文件**，不要强行编造档案。温柔告知用户还没有检测到参考图，引导其两种选择：
     - 把已有的主角图、场景图放进对应文件夹（建议用 `主角.png`、`小猫.png`、`厨房.png` 等直观名字）；
     - 或者手头还没有图的话，直接对你说一句 **「帮我生成资产」**，由你带 ta 从零生成第一套定妆图和场景图。
3. **看图提炼特征**：
   - 对找到的每一张图片，调用 `read_file` 直接查看图像内容。
   - 分别提炼出：
     - **角色/宠物**：准确的相对路径与文件名、角色代号、中文外貌描述（年龄感、脸型神态、发型发色、固定服装款式与颜色、配饰）、以及一段精确到颜色和材质的**英文锚定词（English Anchor Prompt）**。
     - **核心场景**：准确的相对路径与文件名、空间类型、主要家具与厨具位置、窗户朝向与采光、主色调与材质，以及对应的**英文锚定词（English Anchor Prompt）**。
     - **画风参考（如有）**：线稿粗细与颜色、上色笔触、光影对比特点，以及对应的英文风格词。
4. **写入档案**：
   - 读取现有的 `01_资产库/资产档案.md`，保留用户已填写的频道名/水印偏好、目标平台与画幅、常用工具或禁忌项，将扫描结果规范填入「角色清单」「核心场景清单」「画风基调」表格与区块中。
5. **汇报用户**：
   - 用简洁清晰的清单告诉用户已登记了哪些角色和场景，并提醒：“资产档案已建好！如果是第一次尝试，建议对我说 **「生成试水版」**（6–8 个镜头，30–45 秒快速出片）；想直接做完整长版就说 **「生成新一期」**。”

## 流程 B：自动选题与整期工单生成

**触发词**：
- **新手试水版（6–8 镜，30–45 秒）**：「生成试水版」「新手试水」「来一期短的」
- **标准精简版（18–25 镜，1.5–2 分钟）**：「生成新一期」「再来一期」「排一期新视频」「出工单」
- **画幅判断**：默认 `16:9 横屏`；若 `01_资产库/资产档案.md` 中已设定为 `9:16` 或用户当次指令明确提到“竖屏 / 小红书 / 抖音”，则全套生图提示词自动切换为 `9:16 竖屏` 后缀。

### Step 1：前置检查（资产与历史）
1. 读取 `01_资产库/资产档案.md` 并检查 `01_资产库/01_角色参考图/`、`01_资产库/02_核心场景图/` 是否有图。
   - **情况 1**：文件夹里有新图片但 `资产档案.md` 还是空模板 → **先自动执行流程 A** 扫描建档，再继续本流程。
   - **情况 2**：既无任何参考图，`资产档案.md` 里的角色清单和场景清单也都是空的 → **立即停下并引导用户**：说明需要先放入至少 1 张角色图和 1 张核心场景图，或者直接发一句 **「帮我生成资产」** 先生成首套参考图，再回来生成工单。严禁擅自捏造核心资产。
2. 并行读取以下参考文件：
   - `02_选题排期/已生成历史.md`
   - `.agents/skills/ghibli-episode-pipeline/references/topic_matrix.md`
   - `.agents/skills/ghibli-episode-pipeline/references/prompt_guide.md`

### Step 2：自动计算期号与不重样选题
1. 根据 `02_选题排期/已生成历史.md` 确定下一期编号（无记录则为 `EP01`，已有 `EP01` 则为 `EP02`，依此类推）。
2. 严格按照 `references/topic_matrix.md` 的组合池与去重规则，自动抽取 **1 个新主题**：
   - **场景绑定**：剧情必须自然发生在 `资产档案.md` 已登记的场景中，主角与配角/宠物必须来自已登记资产，不可凭空新增常驻角色或大改房屋结构。
   - **去重规则**：不能与历史做过的「具体事件/美食」重复；近 5 期内不重复相同天气时段；不连续两期做同一品类大类。
   - **试水版选片倾向**：若本期为试水版，优先挑选步骤简洁、极易出食欲与治愈感、穿帮风险低的主题（如泡菜锅、番茄拉面、脆皮煎饺、手冲拿铁、厚切黄油吐司、深夜手账）。
   - **主题简称**：提炼一个 4–10 字的无特殊符号中文简称用于建文件夹，例如 `EP01_雨夜泡菜锅`。

### Step 3：创建工单目录与 3 份施工单 + 4 个素材文件夹
在 `03_成片工单/EPXX_<主题简称>/` 下创建以下文件与目录（用 `write_file` 创建占位说明文件来确保空素材目录生成）：
- `素材_图片/把Gemini生成的分镜图存这里_按S01到SXX命名.txt`
- `素材_视频/把图生视频生成的片段存这里_按S01到SXX命名.txt`
- `素材_音频/把环境音和纯音乐存这里.txt`
- `最终成片/剪映导出的完整视频放这里.txt`

并撰写以下 3 份完整施工单：

#### 1. `01_分镜与生图提示词.md`
- **顶部概览**：期号、本期规格（`新手试水版 6–8 镜 / 30–45 秒` 或 `标准精简版 18–25 镜 / 90–120 秒`）、画幅（`16:9 横屏` 或 `9:16 竖屏`）、自动选定的主题与中/英文标题、所属品类、天气时段、总镜头数、预计总时长、出场资产清单与对应参考图路径。
- **分镜结构**：
  - 若为**试水版**：严格按 `topic_matrix.md` 的**三幕试水模板**编排（环境引入 1–2 镜 → 核心制作/仪式高潮 3–4 镜 → 享用与余韵收尾 2 镜）。
  - 若为**标准版**：严格按 `topic_matrix.md` 的**五幕模板**编排（环境引入 3–4 镜 → 准备阶段 4–5 镜 → 烹饪/核心仪式高潮 6–8 镜 → 享用治愈 3–5 镜 → 余韵收尾 2 镜）。
  - 注意远景/中景/特写交替、冷色调与暖色调过渡。
- **逐镜明细表 / 卡片**（`S01` ~ `SXX`，逐镜完整写出，**严禁偷懒省略或写“同上”**）：
  - 镜号与建议时长（例如 `S01 | 5秒 | 远景`）
  - 中文画面描述（清晰说明人物位置、光影、动作状态）
  - **操作：需在 Gemini 上传的参考图**：
    - 精确列出基础资产相对路径，例如 `01_资产库/01_角色参考图/主角.png` + `01_资产库/02_核心场景图/厨房.png`；
    - **【前镜垫后镜】强制规则**：凡是同一锅具、碗碟、桌面或食物的连续推进镜头（例如切好食材 → 下锅煎煮 → 沸腾冒泡 → 盛入同款碗中），**必须明确标注额外上传上一镜刚生成好的图**，例如 `+ 本期素材_图片/S03.png（前镜垫后镜，锁定锅具与食物样式不变）`。
  - **可直接复制进 Gemini 的英文生图 Prompt**：严格遵循 `references/prompt_guide.md` 公式，内嵌 `资产档案.md` 的英文锚定词 + 垫图绑定句（连续镜头必加 `Continue directly from the previous shot reference image...` 衔接绑定句）+ 对应画幅后缀（16:9 或 9:16）+ `no text, no watermark`。
  - 保存文件名：`素材_图片/S01.png`

#### 2. `02_图生视频提示词.md`
- **顶部说明**简明使用方法：
  - 底图放进去，选择 5 秒时长，选对应工具复制对应语言 Prompt；
  - **可灵 / 即梦「首尾帧」进阶省事提示**：凡是相邻两镜画面衔接非常紧密的连续动作（工单中标出建议组别），可在可灵/即梦里试着把 `SXX.png` 放首帧、`S(XX+1).png` 放尾帧，一次生成丝滑过渡；
  - **Veo 3 原生环境音提示**：提示词自带 `Silent character, no dialogue... only soft ambient sound of ...`，如果 Veo 3 生成的片段自带干净的雨声、煎炸声且没人说话，剪辑时可直接留用原声，无需再去下音效。
- 与 `S01` ~ `SXX` **逐镜一一对应**，每镜包含：
  - 上传底图：`素材_图片/S01.png`（若可配合下一镜做首尾帧，注明“可选首尾帧搭档：`S02.png`”）
  - **Veo 3 / 国际模型英文动态 Prompt**：遵循 `prompt_guide.md` 规范，含克制的动作/光影/镜头微动描述 + 强制防人声后缀（`Silent character, no dialogue, no talking, no voice, only gentle ambient sound of ...`）
  - **可灵 / 即梦 中文动态 Prompt**：聚焦局部环境微动、缓慢推拉、轻微神态变化，避免复杂肢体交互
  - **小白防穿帮提示**：如“本镜含手部持筷，优先让热气和雨滴动，人物只做轻微笑/微点头；若手指变形可直接再抽一次或删减到 3.5 秒”。
  - 保存文件名：`素材_视频/S01.mp4`

#### 3. `03_剪辑与音效发布单.md`
- **一、3 层音频方案（兼顾剪映直搜 + Veo 3 省事技巧）**：
  - 顶部先给出 **Veo 3 原生音留用规则**：若该镜用 Veo 3 生成且环境声自然无杂音、无人声，可直接保留视频原声（调至 `-12dB ~ -18dB`），省去单独找音效；其余静音镜头或可灵/即梦生成的无声片段，按下方 3 层方案补音。
  1. 底层持续环境音（全片贯通，音量 `-18dB ~ -22dB`）：同时给出 **剪映自带音效库中文搜索词**（首选，零门槛）与 **免费音效站英文搜索词**（如 `雨打玻璃` / `soft rain on window ambient`）。
  2. 中层 ASMR 卡点音效表（精确列出哪个镜号配什么声音、音量 `-12dB ~ -16dB`）：每行同时给出 **剪映音效库中文直搜词** 与 **英文备用词**。
  3. 顶层轻音乐 BGM（音量 `-24dB ~ -28dB`）：给出 **剪映音乐库中文直搜词**（如 `治愈系纯钢琴`、`温暖木吉他`）以及 **YouTube Audio Library 免费方向**（如 Aakash Gandhi 风格轻钢琴）。
- **二、剪映（CapCut）极简剪辑 Checklist**：
  - 时间轴导入顺序、90% 硬切 + 幕间 0.5 秒叠化、全片微调暖色色温/轻微暗角与胶片颗粒以统一不同镜头色差、右下角添加半透明频道水印（读取 `资产档案.md` 中的水印文本）。
- **三、封面与双平台发布包装**：
  - **无字封面推荐**：指定 **2 个最适合做无字封面** 的镜号（直接拿 `素材_图片/SXX.png` 略提饱和度即可，**不加文字**）。
  - **YouTube 海外发布包**：
    - **3 组中/英双语标题**（符合 `[天气/季节情绪] + [具体生活/美食动作] + [治愈关键词]`）
    - **YouTube 简介模板** + **按本期镜头累加时长算好的章节时间戳**（试水版 3 个章节，标准版 5 个章节）+ **20 个中英文 SEO 标签**
    - **合规提醒**：发布时在 YouTube Studio 勾选「经过修改或合成的内容（Altered or synthetic content）」。
  - **国内平台（小红书 / 抖音 / B站）速贴发布包**：
    - **3 个中文高点击治愈标题**
    - **1 段简短有氛围感的正文文案** + **10 个中文热门话题标签**（如 `#治愈系动画 #AI动画 #沉浸式做饭 #深夜食堂 #吉卜力风`）
    - **合规提醒**：发布时按平台提示勾选/声明「AI 生成内容」标识。

### Step 4：更新历史记录与汇报
1. 将本期记录追加写入 `02_选题排期/已生成历史.md` 表格（含 `规格` 列，如 `试水版 16:9` 或 `标准版 16:9`），状态设为 `待制作`。
2. 在回复中向用户简要展示：
   - 本期规格（试水版或标准版）、画幅与总镜头数
   - 本期自动选定的主题与选片理由（为何贴合现有资产且不撞车）
   - 工单文件夹及 3 份施工单的可点击链接
   - “接下来先做什么”的 3 步极简指引（打开 `01_分镜与生图提示词.md` → 照着贴图和前镜垫后镜出图 → 接着做视频与剪映合成）。

## 流程 C：单镜修复与排期维护

### C-1：单镜穿帮修复（「EPXX 第 X 镜穿帮了/帮我改」「优化镜头」）
1. 定位 `03_成片工单/EPXX_*/01_分镜与生图提示词.md` 与 `02_图生视频提示词.md`。
2. 读取对应镜号的内容及 `资产档案.md`。
3. 诊断常见原因（手部握持特写过多、双人复杂互动、物体在画面中大跨度移动、未做前镜垫后镜导致道具变样、镜头描述过于拥挤等），保留原剧情目的与角色/场景锚定词，**切换成更稳妥的替代构图或微动方案**（例如：特写改成略带前景虚化的中景、夹菜动作改成“端着碗热气腾腾微笑”或“食物表面热汤冒泡特写”）。
4. 使用 `edit_file` 更新对应工单中的该镜头，并清楚告诉用户改了哪里、需要重新生成图片还是只重抽视频即可。

### C-2：排期维护（「标记 EPXX 已完成」「查看排期」）
- 读取 `02_选题排期/已生成历史.md`。
- 若是查看排期，清晰总结已制作、待制作数量及上一期主题与规格。
- 若是标记完成，使用 `edit_file` 将对应期号状态从 `待制作` 改为 `已完成 (YYYY-MM-DD)`，并告知用户当前累计已完成期数。
