## 二、去重与轮换规则

每次自动选题时，先检查 `02_选题排期/已生成历史.md`：
1. **具体事件零重复**：历史上已经生成过的「具体事件/美食」（例如第 2 题“韩式泡菜豆腐暖锅”）绝不再次抽取，除非 32 个全部轮完。
2. **品类轮换**：本期选用的「品类大类（A/B/C/D）」**不得与上一期相同**，保证频道页面既有热汤热面，也有煎烤、甜品和日常仪式，保持新鲜感。
3. **天气防撞车**：近 5 期历史中出现过的「天气与时段」尽量避开，优先挑选与最近一期反差较大的季节或光影。
4. **资产按需沉淀与优先复用**：当资产库已沉淀有常用场景（如厨房、窗边书桌）时，优先兼顾复用已有场景降低补图成本；但若用户想要新故事或为了丰富频道需要引入新场景（如阳台、露营车、老书店、雪夜木屋等），完全允许先定剧情再按需补画 1 张空景图存进 `01_资产库/02_核心场景图/`，存过一次后永久复用。
5. **试水版选片倾向**：如果是生成「新手试水版」，优先抽取步骤简洁、局部微动好出片、不易手部穿帮的主题（如：2 韩式泡菜豆腐暖锅、1 番茄肥牛拉面、9 脆皮煎饺、10 厚切黄油吐司配滑蛋、17 手冲肉桂热拿铁、25 深夜窗边手账与热茶陪伴）。

## 三、双规格分镜结构模板

### 1. 新手试水版：30–45 秒三幕分镜模板（6–8 镜，推荐第 1 期使用）

总时长目标 **30–45 秒**，单镜建议 **4.5–5 秒**（实际剪辑时每镜取最稳的 4–5 秒）。适合低成本快速跑通第一条成片：

| 幕次 | 建议镜数 | 时长占比 | 情绪与景别安排 |
| :--- | :--- | :--- | :--- |
| **第 1 幕：环境引入** | 1–2 镜 | 0:00–0:08 | 窗外天气远景或窗玻璃雨雪特写 → 切入暖灯室内与主角入场（建立冷暖对比） |
| **第 2 幕：核心制作/仪式高潮** | 3–4 镜 | 0:08–0:28 | 直接聚焦最解压、最具食欲的 3–4 个关键步骤（备料/下锅滋啦/汤滚冒泡/主角温柔看锅），**连续特写采用“前镜垫后镜”锁定锅具与食物不变样** |
| **第 3 幕：享用与余韵收尾** | 2 镜 | 0:28–0:40 | 成品端上桌热气特写 → 主角端起碗/捧起热杯满足微笑 + 室内暖光定格淡出 |

### 2. 标准精简版：1.5–2 分钟五幕分镜模板（18–25 镜）

总时长目标 **90–120 秒**，单镜建议 **4.5–5 秒**（实际剪辑时每镜取最稳的 3.5–5 秒）：

| 幕次 | 建议镜数 | 时长占比 | 情绪与景别安排 |
| :--- | :--- | :--- | :--- |
| **第 1 幕：环境引入** | 3–4 镜 | 0:00–0:20 | 远景定基调（窗外天气）→ 窗户雨/雪/光线特写 → 人物入场/开暖灯切换暖色调 |
| **第 2 幕：准备阶段** | 4–5 镜 | 0:20–0:45 | 拿取器皿中景 → 备料/洗切/研磨**微距特写** → 宠物/周边环境穿插镜头 |
| **第 3 幕：烹饪/仪式高潮** | 6–8 镜 | 0:45–1:25 | **全片最核心！** 大量使用高食欲/高声音潜力的特写与中近景（下锅滋啦声、汤滚冒泡、热气升腾、金黄翻面/精细手作），交替人物专注神情，**连续道具镜头必用“前镜垫后镜”** |
| **第 4 幕：享用与治愈** | 3–5 镜 | 1:25–1:48 | 成品端上桌高颜值特写 → 人物吹气品尝/满足微笑中景 → 宠物陪伴/窗外与室内呼应 |
| **第 5 幕：余韵收尾** | 2 镜 | 1:48–2:00 | 窗外天气趋于温柔/夜色更静 → 室内暖光远景定格，情绪慢慢沉淀淡出 |
