# 治愈系手绘动画短片 — 小白 5 步牵手指南

欢迎来到你的专属创作工作台！这套工作台模仿 `@GhibliDayss` 频道的高爆款模式，**先定剧情与穿搭，再按需补齐缺失的场景/宠物图（用过就存进资产库，以后遇到同样场景直接复用）**。全程一次只带你做一步，不用自己瞎摸索！

---

## 一、文件夹是干嘛的？

```text
吉卜力治愈系\
├── 01_资产库\          ← 【按剧情按需沉淀】主角、宠物、用过的房间图（存过一次，以后直接复用）

```

## 二、全程 5 步牵手实操流程（每做完一步发一句口令）

> **💡 万能防迷路口令**：任何时候忘了现在该干嘛、或者中途停下隔天再做，只要在聊天框发一句 **`下一步`**，我会自己检查文件夹里已经有哪些图/视频，精准告诉你接下来做什么！

### 第 1 步：定剧情与穿搭（支持横屏 & 竖屏）
- **你只需发**：**`定剧情`** 或 **`生成试水版`**（第 1 期强烈推荐试水版：只要 6–8 镜，约 30–45 秒；想要 1.5–2 分钟标准版发 **`生成新一期`**；要发小红书/抖音竖屏加上“竖屏”二字即可）。
- **我会帮你做**：结合历史不重样地定好本期故事、天气时段，并按题材搭配一套**温暖复古日系居家穿搭**（主角**锁脸锁发型、不锁死衣服**——做饭可配围裙，书桌/客厅不穿围裙）。

### 第 2 步：查资产库（已有直接复用，缺啥只补画啥）
- **我会帮你做**：先核对 `01_资产库/` 里现有的图。**已经有的角色和场景直接复用**；只有本期新用到、库里还没有的场景或小动物，我才给你写 Gemini 提示词去补画那 1–2 张。
- **你只需做**：去 Gemini 照提示词生好缺失的图，放进 `01_资产库/` 对应文件夹后，回来发一句 **`补好了`**（系统会永久记住这张新图，以后再遇到同场景直接跳过这一步）。

### 第 3 步：拿工单去 Gemini 生成分镜图
- **我会帮你做**：在 `03_成片工单/EPXX_xxx/` 里自动建好 3 份施工单和 4 个素材文件夹。
- **你只需做**：打开工单里的 `01_分镜与生图提示词.md`，对着 `S01`、`S02`... 上传对应参考图（含“前镜垫后镜”防锅具和食物变样）并复制英文 Prompt，存进 `素材_图片/`。全部存完回来发 **`下一步`**。

### 第 4 步：去 Veo / 可灵 / 即梦 图生视频
- **你只需做**：打开工单里的 `02_图生视频提示词.md`，逐个上传 `素材_图片/S01.png` 等底图，选 5 秒时长：
  - 用 **Veo 3 / 国际模型** → 复制**英文动态 Prompt**（内置防人声静音后缀，还会生成自然雨声/煮汤声）；
  - 用 **可灵 / 即梦 / 海螺** → 复制**中文动态 Prompt**（相邻连续镜头可按提示用「首尾帧」模式）。
- 遇到某镜穿帮/手变形，直接发 **`EP01 第 X 镜穿帮了，帮我改`**。视频全存进 `素材_视频/` 后，回来发 **`下一步`**。

### 第 5 步：剪映配音合成 + 发布
- **你只需做**：打开 `03_剪辑与音效发布单.md`：
  - 用 **Veo 3** 且原生雨声/煮汤声干净没人说话的镜头，可直接留用视频原声；其余按清单里的**剪映自带音效库中文搜索词**直接搜；
  - 按顺序排好片段、挑推荐的无字封面、复制准备好的双平台标题和文案，导出到 `最终成片/`，发布时记得勾选 **「AI 生成内容」** 声明！
- 发布完回来发一句 **`做完了`**，自动归档排期，随时开启下一期！

## 三、常用口令速查表（复制即用）

| 你想做什么 | 直接跟我说什么 |
| :--- | :--- |
| 不确定当前做到哪一步了（随时可用） | **下一步** |
| 第 1 期先做个 30–45 秒短版试水 / 定剧情 | **定剧情** 或 **生成试水版**（可加“竖屏”） |
| 出完整 1.5–2 分钟新一期 | **生成新一期**（可加“竖屏”） |
| 刚把缺少的场景/宠物图放进资产库 | **补好了**（或 **扫描我的资产库**） |
| 某一个镜头生成得怪、手指变形 | **EP01 第 X 镜穿帮了，帮我改** |
| 这期已经导出发布完了 / 看看排期 | **做完了** 或 **查看排期** |
