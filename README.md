# 治愈系手绘动画短片 — 小白一键流水线指南

欢迎来到你的专属创作工作台！这套工作台模仿 `@GhibliDayss` 频道的高爆款模式，**不需要你想主题、不需要你懂英文提示词、哪怕手头一张图都没有也能从零起步**，每次说一句话就能自动拿整套施工单。

---

## 一、文件夹是干嘛的？

```text
ff\
├── 01_资产库\          ← 【只弄一次】放你的主角、宠物、厨房/房间参考图
├── 02_选题排期\        ← 【全自动】记录做过哪些主题和规格，防止撞车
└── 03_成片工单\        ← 【每期一个夹】每次出新视频，全套分镜和提示词都在这里
```

---

## 二、第一次使用（只需做 1 次，没图也能起步！）

- **情况 A：手头还没有主角图和房间图（零基础推荐）**
  1. 直接在聊天框发一句：
     > **帮我生成资产**
  2. 回答 3 个超简单的问题（主角长啥样、带不带小猫、主要在厨房还是书桌），我会把定妆图英文提示词直接写给你，带你去 Gemini 画出第一套画风统一的主角与房间图。
  3. 把生好的图存进 `01_资产库/01_角色参考图/` 和 `02_核心场景图/`，再说一句 **「扫描我的资产库」** 即可。

- **情况 B：已经有准备好的参考图**
  1. 把**角色/宠物图**放进 `01_资产库/01_角色参考图/`（比如 `主角.png`、`小猫.png`）。
  2. 把**固定场景图**放进 `01_资产库/02_核心场景图/`（比如 `厨房.png`、`窗边书桌.png`）。
  3. 回到这个聊天窗口，直接发一句：
     > **扫描我的资产库**
  4. 我会自动看图并把所有细节写进 `01_资产库/资产档案.md`（频道名、水印文字、常用视频工具和默认横竖屏都可以顺便告诉我）。

## 三、出片双模式选择（支持横屏 & 竖屏）

你可以根据自己的精力自由选择两种规格：

1. **新手试水版（强烈推荐第 1 期使用！）**
   - 聊天框发送：**`生成试水版`**
   - **只要 6–8 个镜头（约 30–45 秒）**，大约 1 小时就能低成本跑通第一条完整动画，先尝到出片的成就感！
2. **标准精简版（熟练后量产正片）**
   - 聊天框发送：**`生成新一期`**
   - **18–25 个镜头（约 1.5–2 分钟）**，适合发 YouTube、B站等横屏长视频。
3. **想发小红书 / 抖音竖屏？**
   - 只要在指令里加上“竖屏”两个字就行，比如 **`生成试水版，我要发小红书竖屏`**，全套提示词会自动切为 `9:16 竖屏`。

## 四、4 步极简实操流程

### 第 1 步：一键出题 + 出整套工单
直接在聊天框发 **`生成试水版`** 或 **`生成新一期`**，系统会自动挑一个不重样的治愈主题，在 `03_成片工单/EP01_xxx/` 里建好全套文件。

### 第 2 步：去 Gemini 生成分镜图（带“前镜垫后镜”防变样）
1. 打开工单里的 `01_分镜与生图提示词.md`。
2. 对着每一个镜头（`S01`、`S02`...）：
   - 看清提示里写着**“需要上传哪几张参考图”**，拖进 Gemini（遇到切菜→下锅→煮沸这种连续镜头，按提示多拖一张**上一镜刚生好的图**，锅和食物就不会变样！）；
   - 复制对应的**英文生图 Prompt** 发送；
   - 把生好的图片按指定名字（`S01.png`、`S02.png`...）存进 `素材_图片/` 文件夹。

### 第 3 步：去 Veo / 可灵 / 即梦 图生视频
1. 打开工单里的 `02_图生视频提示词.md`。
2. 逐个上传 `素材_图片/S01.png` 等底图，选择 5 秒时长：
   - 用 **Veo 3 / 国际模型** → 复制**英文动态 Prompt**（已内置防说话静音指令，还会生成自然雨声/煮汤声）；
   - 用 **可灵 / 即梦 / 海螺** → 复制**中文动态 Prompt**（相邻连续镜头还可以按提示尝试「首尾帧」模式，过渡更丝滑）。
3. 如果遇到某个镜头手变形或穿帮，回来跟我说一句：**`EP01 第 4 镜穿帮了，帮我改`**，我会立刻帮你重写成稳妥版本。
4. 把生成的视频按 `S01.mp4`、`S02.mp4`... 存进 `素材_视频/` 文件夹。

### 第 4 步：在剪映拼接 + 配音 + 发布
1. 打开 `03_剪辑与音效发布单.md`。
2. **省事配音技巧**：
   - 如果你用的是 **Veo 3**，而且某个片段自带的雨声、锅里冒泡声很干净也没人说话，**可以直接保留视频原声**，不用重复找音效！
   - 用可灵/即梦或需要补音效的片段，直接照着清单里的**剪映自带音效库中文搜索词**（如 `小雨声`、`炒菜滋啦`、`轻钢琴`）一搜就能用，不用折腾外网下载。
3. 在剪映里按顺序排好视频片段，选里面推荐的 **无字封面图**，直接复制里面准备好的 **YouTube 双语包** 或 **小红书/抖音/B站中文发布包**，发布时记得勾选 **「AI 生成内容」** 声明！
4. 发布后对我说：**`标记 EP01 已完成`**，方便下次自动排期。
